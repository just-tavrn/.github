# Getting help

- **Questions, setup help, ideas:** ask in [Discussions](https://github.com/just-tavrn/.github/discussions).
  Search first; your question may already have an answer.
- **Running a node:** the operator documentation is in the README of
  [tavrn-node](https://github.com/just-tavrn/tavrn-node) (installation, reverse proxy, voice, federation,
  legal setup).
- **Building a client or a bot:** start with the protocol in
  [tavrn-protocol](https://github.com/just-tavrn/tavrn-protocol) and the packages in
  [tavrn-js](https://github.com/just-tavrn/tavrn-js) (`@tavrn/sdk`, `@tavrn/bot`).
- **Bugs and feature requests:** open an issue in the repository of the affected component (see
  [CONTRIBUTING.md](CONTRIBUTING.md#where-things-live)).
- **Security vulnerabilities:** never in public; follow the [security policy](SECURITY.md).

tavrn is maintained by volunteers. There is no paid support; we answer when we can. If a node you use is
run by someone else, contact its operator first: they configure it and can see what went wrong.
